# 纸感设计的温度：CSS 造出「墨纸森系」

> 从噪点纹理到衬线排版，聊聊如何用纯 CSS 打造有质感的轻量视觉风格。

## 为什么选择纸感

主流网站设计越来越趋同：白底、大圆角、柔和阴影、无衬线大字。它们高效，但缺少一点**温度**。

纸张就不一样：它有纹理、有颜色、有轻微的触感记忆。把「纸」的意象带进网页，界面会立刻变得亲切起来。

## 三个关键手法

### 1. 噪点纹理

纯色背景在屏幕上往往显得太「平」。用 SVG 的 `feTurbulence` 滤镜生成一层极淡的噪点，叠在背景上，就有了纸张的颗粒感：

```css
background-image: url("data:image/svg+xml,...feTurbulence...");
```

关键是把 `opacity` 控制在 0.05 左右——太明显会脏，太淡则无感。

### 2. 衬线标题 + 无衬线正文

标题用衬线字体（Georgia / 宋体），正文用无衬线字体，形成优雅的对比：

```css
--font-serif: "Georgia", "Songti SC", serif;
--font-sans: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
```

衬线字承担情绪，无衬线字承担可读性，各司其职。

### 3. 细节装饰

小元素能让风格立起来：

- 印章式圆形 Logo（旋转几度，更有手工感）
- 细线分隔（1px 半透明墨绿）
- 卡片不用大圆角，4–8px 即可，保持「纸」的硬朗

## 色彩系统

我使用了一个克制的色板：

| 角色 | 色值 | 用途 |
| ---- | ---- | ---- |
| 米纸底 | `#F7F3EA` | 页面背景 |
| 墨色 | `#222A25` | 正文文字 |
| 松墨绿 | `#2F6B4F` | 主强调 |
| 焦糖 | `#C9793F` | 点缀 |

## 小结

纸感设计的关键不是「模拟纸张」，而是**借用纸张的克制与温度**。少一点饱和、多一点留白、加一点纹理，界面就有了呼吸感。不妨在自己的项目里试试。
